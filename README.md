Spot the Difference — Curious Corners: two near-identical hand-painted pictures side by side, 22 differences hiding across three original scenes (a Sunny Garden, a Harbour at Dusk, and a Night Market). Click a difference on either picture to circle it, chain finds into combos, spend limited hints, and beat the clock. Every scene is drawn with Canvas 2D and every sound is synthesized with WebAudio — no image or audio files, no network requests, mouse and keyboard play.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Click a difference on either picture (or press H for a hint, R to restart, 1/2/3 to jump to a scene, M for sound).
